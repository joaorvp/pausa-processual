# Pausa Processual

**A pressão invisível do trabalho jurídico.**

Protótipo de aplicativo web para ajudar profissionais da área jurídica (advogados, assessores e estagiários) a lidar com a cultura de urgência permanente e a se desligar do trabalho ao fim do expediente.

🔗 **Acesse o protótipo:** https://joaorvp.github.io/pausa-processual/

## Funcionalidades

1. **Triagem de urgências**: registre uma demanda e classifique como *urgente hoje*, *pode esperar* ou *agendar*, com o prazo real. Três perguntas rápidas sugerem a classificação (há prazo fatal hoje? há prejuízo concreto se ficar para amanhã? depende de outra pessoa?).
2. **Encerrar o expediente**: ritual guiado de 2 minutos para revisar o que era urgente, anotar o que fica para amanhã e gerar uma mensagem de encerramento.
3. **Pausa e apoio**: respiração guiada de 1 minuto, sugestões de pausas curtas e acesso rápido à rede de apoio (CVV 188, SAMU 192, CAPS e CAA-DF).

## Privacidade

Sem cadastro e sem servidor: as informações ficam salvas apenas no navegador de quem usa (`localStorage`), em respeito à LGPD. O aplicativo não faz diagnóstico nem substitui atendimento profissional.

## Contexto

Projeto de Extensão do curso de Análise e Desenvolvimento de Sistemas do IESB (Trilha Inovação e Criatividade, tema norteador Saúde Mental, ODS 3, 5, 8 e 16). A solução foi construída a partir de entrevistas de empatia e de um questionário com profissionais jurídicos de um departamento jurídico corporativo e de escritórios de advocacia do Distrito Federal.

## Tecnologia

HTML, CSS e JavaScript puros, em um único arquivo (`index.html`), publicado com GitHub Pages.
